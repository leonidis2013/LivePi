No password is set. Plugin upload, delete, updates and reboot are disabled until you set one. On the Pi run: sudo /opt/livehost/set-password.sh or trust your control network: sudo /opt/livehost/trusted-network.sh add 192.168.1.0/24
Listen Plays the chosen signal on this device. It only reads a copy of the audio, so it does not take priority over the main inputs and outputs.

Audio device

Lower buffer = lower latency but more CPU. Watch the xrun counter at the top.
No audio interface? Choose the type Virtual (no audio hardware): the input becomes a test tone, noise, sweep or an audio file of your own, and the output is discarded. Use Listen on the Mixer tab to hear the result.
A test file (for example a spoken voice recording, up to 10 minutes) appears as the input Test file (loop) of the virtual card.

Channels

With one channel the output feeds both L and R.

Plugins on this Pi

Drop a .zip, a .vst3 folder or a .vst3 / .so file here, or choose below
Plugins must be Linux ARM64 builds (they need Contents/aarch64-linux/*.so). A bare .so/.vst3 file is wrapped into a bundle for you.
