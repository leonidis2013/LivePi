Access is locked. Without a password, plugin upload, plugin windows, updates and reboot only work from a trusted network, and this device () is not in one. Set a password on the Pi (sudo /opt/livehost/set-password.sh), or unlock: sudo /opt/livehost/trusted-network.sh open
Listen Plays the chosen signal on this device. It only reads a copy of the audio, so it does not take priority over the main inputs and outputs.

Audio interface

Smaller buffer = lower latency but more CPU. Watch the xrun counter at the top.

Simulated sound card

No hardware needed: the input is a test tone, noise, sweep, silence or your own audio file, and the output is discarded. Use Listen on the Mixer tab to hear the result.
A test file (for example a spoken voice recording, up to 10 minutes) appears as the input Test file (loop).

Channels

With one channel the output feeds both L and R.

Plugins on this Pi

Drop a .zip, a .vst3 folder or a .vst3 / .so file here, or choose below
Plugins must be Linux ARM64 builds (they need Contents/aarch64-linux/*.so). A bare .so/.vst3 file is wrapped into a bundle for you.

System

After a restart or reboot, wait about 30 seconds and this page reconnects.
